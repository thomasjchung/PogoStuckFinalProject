## Post Mortem

The following few paragraphs are a discussion about what we are proud of, things we wish we could have done, and just overall our thoughts about the project!

There are a few natural extensions to this project. Firstly there is lots of room for more creative freedom within the level create. We were able to implement a few core blocks like stone, dirt, wind, and ice. Of these only a few had interesting interactions. For example, a player would maintain momentum on ice due to a lower coefficient of friction, stone blocks would shake and disappear after a few seconds, and a player would have their horizontal velocity slightly augmented by the wind blocks. We wish we had far more time to implement more interesting blocks like water, sticky blocks, sliding blocks, etc. This would allow for far more dynamism within the gameplay experience as well as far more freedom for users to create interesting and exciting levels. There is also plenty of room for improvement within the gameplay experience itself. For example more interactive sounds could be added which differ by block. We were also thinking to make the gameplay slightly more difficult by adding a constant bouncing mechanic, however we decided it would be both time consuming to implement and potentially too hard.

Although there are certainly areas for improvement as mentioned above we are still incredibly proud of the game we created! Many things went well but most importantly we feel we captured the soul of a game which induces rage in the player. After falling down 3 levels on my best attempt we were just as furious as we hoped. Additionally we felt that the creative aspect of being able to develop our own levels with some aesthetic augmentation, via pixel art we made, was incredibly fun. The small features in level create took a lot of time but we feel that they solidify the game in terms of feel and look. Things like sliding on ice and grass blocks only appearing at the top of dirt chunks are fantastic little touches that we loved implementing.

If we had more time we would certainly proceed with the various improvements we listed within the first paragraph. However we also would restructure the game slightly to make it more easily extensible and compartmentalized. We learned throughout the course of this class just how important that is, and although we did not ignore this lesson entirely, the new aspect of pushing code in sync, understanding each others commits, and working on our own local branches meant that sometimes we were more concerned on implementing objectives than looking ahead. This led to code which did not rely as heavily on components and clear distinctions in the codebase. If we had more time we certainly would have focused on this, and we feel it would have naturally led to an easier time of implementing the improvements we listed in the first paragraph.

Over the course of this final project, we had a great time working together as a team to create something that we are both very proud of. We feel we were able to get to the end goal that we hoped, and we’re excited to keep working on this as a side project. We are incredibly grateful to Professor Shah and the course staff for the lessons we’ve learned over the course of the past semester, and we hope anyone reading this will get to enjoy our project as much as we did!
